# Star Catch

Subscribe to a codebase and find out what actually changed, without reading a single diff.

A merged pull request becomes a short narrated update — synced scenes with narration, plus an article — delivered to people who depend on the software but don't read its code.

This repository holds the plan, the study and the backend. The pages live in Crux.

## Start here

1. [ROADMAP.md](ROADMAP.md) — every step, in order, as a checklist.
2. [docs/diagrams/infrastructure.svg](docs/diagrams/infrastructure.svg) — what runs where.
3. [docs/tasks/03-scaffold-backend.md](docs/tasks/03-scaffold-backend.md) — the first open task; paste its prompt into a Claude Code session.
